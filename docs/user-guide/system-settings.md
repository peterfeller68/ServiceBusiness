# System Settings

Last reviewed: 2026-08-05

System Settings control deployment-level behavior such as Pool or Landscape mode and DevTest mode.

## Opening Settings

The `/settings` page is a read-only settings overview. System Administrators can see:

- SystemMode
- DevTest
- Product

The page also shows the Azure App Service setting names used by operators.

## SystemMode

Pool mode uses PoolShark branding and Pool Equipment features.

Landscape mode uses TreeShark branding and hides Pool Equipment features.

## DevTest

DevTest mode enables test sign-in and Test navigation. It should be enabled only in development or testing environments.
