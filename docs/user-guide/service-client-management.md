# Service Client Management

Last reviewed: 2026-08-05

System Administrators use Service Clients to manage the businesses that use the service platform.

## Opening Service Clients

Open System Administrator / Service Clients.

The page lists service clients for the current Pool or Landscape mode.

## What You Can See

The Service Clients table shows:

- Status
- Name
- Type
- Service Package
- Email
- Phone

## Editing Service Clients

Use the edit action to update service client type, name, business email, business phone, service package, time zone, and active status.

The active toggle changes whether the service client is active. The delete action currently archives the service client by setting it inactive.

## Service Package Assignment

A service client can be assigned an active global service package for the current service type.
