# Catalog Services

Last reviewed: 2026-08-05

The Services page manages the services that can be planned, performed, and billed during service work.

## Opening Services

- System Administrators open Settings / Services.
- Business Owners open Settings / Services.
- Independent Home Owners open Settings / Services.

System Administrators work with the current app-mode starter catalog. Business Owners work with their service client catalog. Independent Home Owners work with their own service list.

## What You Can See

The Services table shows active status, name, category, description, and actions.

Business Owner and System Administrator views also show duration, default price, and taxable status.

Use the filter box to search. Select a column heading to sort.

## Creating Or Editing Services

Use Create or the edit action to open the inline service editor.

Service fields include category, name, description, active status, and, for business catalogs, duration, default price, and taxable status.

## Adding Starter Services

Business Owners and Independent Home Owners can use Add Services to search the global starter catalog and choose a service. The selected service is added to the current catalog so it can be edited without changing the global starter record.

## Seed Services

System Administrators can seed the starter catalog from a CSV file with these columns:

- Category
- Name
- Description

## Delete And Archive Notes

Service categories use active/archive behavior. The current service-row delete action removes the service row from the catalog.
