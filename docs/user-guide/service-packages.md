# Service Packages

Last reviewed: 2026-08-05

Service Packages define a recurring bundle of services and the package cost. They can be assigned to service clients or individual business clients.

## Opening Service Packages

- System Administrators open Settings / Service Packages.
- Business Owners open Settings / Service Packages.

System Administrators manage the current service type's global packages. Business Owners manage packages for their own service client.

## What You Can See

The Service Packages table shows:

- Active status
- Name
- Recurrence
- Description
- Cost
- Included services

Use the filter box to search by active state, name, recurrence, cost, description, or included service. Select a column heading to sort.

## Creating Or Editing A Package

Use Create or the edit action to open the inline editor.

Package fields include name, recurrence, cost, active status, and description.

Allowed package recurrence values are:

- Weekly
- Bi-Weekly
- Monthly
- Bi-Monthly
- Half-Yearly
- Yearly

## Choosing Services

Chosen Services shows services already included in the package. Choose Services lists available services that can be added.

Business Owners can choose from active company services and active global starter services. System Administrators choose from active global services.

Each included service can run Every Visit or Every X Visits.

## Active, Archive, And Delete

The active toggle controls whether a package is active. The delete action currently removes the package row.

## Client Assignment

Service packages can be assigned from Service Client Management or Business Client Management. Business Clients can view their assigned package from the dashboard.
