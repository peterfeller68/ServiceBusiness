# Test Mode And Test Users

Last reviewed: 2026-08-05

Test Mode is for development and QA. It allows seeded test users to sign in without Google authentication when DevTest is enabled.

## Test Sign In

When DevTest is enabled, Sign In shows a test user id/email field and Skip Google Auth button.

Only users marked as test users can use this flow.

## Test Navigation

When DevTest is enabled, the navigation includes Test:

- Test Page
- Test Users

## Test Users

Test Users lets testers create or edit development accounts.

Supported user types are:

- System Admin
- Business Owner
- Business Employee
- Business Client
- Homeowner
- General Test User

Business Owner, Business Employee, and Business Client test users require an associated business. Test users can also be marked as pending approval, disabled/reactivated, and configured with notification settings.
