# Pool Configuration

Last reviewed: 2026-08-05

Pool Configuration records the equipment installed for a specific pool. It is separate from the global Pool Equipment starter catalog.

## Opening Pool Configuration

- System Administrators open Settings / Pool Configuration.
- Business Owners open Settings / Pool Configuration.
- Independent Home Owners open Settings / Pool Configuration.
- Business Clients can view Pool Configuration on the dashboard.

Pool Configuration is available only in Pool mode.

## Choosing A Client

System Administrators and Business Owners choose which client pool to manage.

System Administrators can choose active Pool business-client addresses and independent homeowner profiles. Business Owners can choose active business clients in their own service client company.

Independent Home Owners manage their own pool configuration directly.

## Configuration Table

The Configuration table shows:

- Manufacturer
- Name
- Category
- Model No
- Comment

Use the filter box and column headers to find and sort configured equipment. Use the comment field to save a quick equipment note.

## Adding Equipment

Use Add Pool Equipment to search global starter equipment by manufacturer, name, model, category, or description. Choose a row to add it to the selected pool configuration.

Use Create to add custom configured equipment. The editor supports category, manufacturer, name, model number, image URL, description, comment, and active status.

## Pictures

Use Equipment Pictures to upload one or more images for the selected pool configuration. Uploaded pictures can be opened larger or deleted.

## Delete Notes

The delete action currently removes the configured equipment row or picture.
