# Pool Equipment Catalog

Last reviewed: 2026-08-05

Pool Equipment supports the global starter equipment catalog. Pool-specific configured equipment is covered in [Pool Configuration](pool-configuration.md).

## Opening Pool Equipment

- System Administrators open System Administrator / Pool Equipment to manage the global starter catalog.

Pool Equipment is available only in Pool mode.

## Global Equipment Catalog

The global catalog table shows active status, manufacturer, name, category, model number, description, and actions.

System Administrators can create equipment categories and equipment items, edit existing rows, toggle active status, delete equipment rows, and seed equipment from CSV.

The seed CSV must include these columns:

- Manufacturer
- Category
- Name
- Model No

## Related Pool Configuration

System Administrators, Business Owners, and Independent Home Owners use [Pool Configuration](pool-configuration.md) to manage configured equipment and pictures for a specific client or homeowner pool.
