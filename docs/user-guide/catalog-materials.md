# Catalog Materials

Last reviewed: 2026-08-05

The Materials page manages material items that can be used during service work.

## Opening Materials

- System Administrators open Settings / Materials.
- Business Owners open Settings / Materials.

System Administrators work with the current app-mode starter catalog. Business Owners work with their own service client catalog.

## What You Can See

The Materials table shows active status, manufacturer, name, category, model number, unit, billable price, description, and actions.

Use the filter box to search by active state, manufacturer, name, category, model, unit, price, or description. Select a column heading to sort.

## Creating Or Editing Materials

Use Create or the edit action to open the inline material editor.

Material fields include category, manufacturer, name, model number, unit, unit cost, billable price, description, taxable status, and active status.

## Adding Starter Materials

Business Owners can use Add Materials to search the global starter catalog and choose a material. The selected material is added to the company catalog so it can be edited without changing the global starter record.

## Seed Materials

System Administrators can seed the starter catalog from a CSV file with these columns:

- Brand
- Category
- Name
- Model No

## Archive And Reactivate

The active toggle controls whether a material is active. The delete action currently archives the material by setting it inactive.
